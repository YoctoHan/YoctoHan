### § 1 — Notes

I trained as a mathematician (MSc) and now build the infrastructure that large language models run on: training and inference frameworks, high-performance computing, and the CUDA kernels underneath. I like the problems where the profiler disagrees with the whiteboard — a kernel that should be faster, a pipeline that stalls, a bound that ought to be tight.

**On the bench right now:** LLM inference optimization, CUDA programming, algorithms. The through-line is depth in performance and systems work.
